想讓 Gemini 學會執行特定的工作，很多工程師以為一定要寫程式或整理一長串的提示語。更誤以為手機版是無法建立新技能(Skill)的。本篇短文要說明手機板的Gemini Skill建立新技能的簡易做法，把 GitHub 專案網址貼進對話，加一句「建立新技能」，Gemini 會自己讀專案，寫好名稱、說明與指令三個欄位。本文以開源專案 iso-explode-film（等軸爆炸圖）為例，從選單一路點到產出即熱式飲水機的爆炸圖與拆解動畫，最後説明手機上建立的技能和原專案在電腦執行版本的差異。

PART 01

技能是什麼？iso-explode-film 又是什麼？

定義

Gemini 技能是一組存起來、可重複使用的指令，告訴 Gemini 某一類工作要怎麼做。依 Google 官方的 Gemini 技能介紹頁，技能可以用 Gemini 代寫、套用範本、手動撰寫或上傳 skill 檔建立，使用時在對話框輸入斜線/加技能名稱呼叫，請求內容符合技能說明時 Gemini 也會自動套用。官方同一頁也說明 Gems 將轉移為技能，舊的 Gems 會自動搬過去，實際時程以 Google 公告為準。

iso-explode-film 是作者 Warrickchenxin 在 GitHub 公開的 Skill，採 MIT 授權。依專案 README，它的用途是把實體產品做成 30 秒的等軸測拆裝廣告片，輸入可以是 CAD、網格模型、工程圖或幾張照片。

操作步驟

本例在 PART 03 建好技能後，回到技能清單點進 iso-explode-film，會看到 Gemini 寫好的三個欄位。

  1. 名稱沿用 GitHub 專案名稱 iso-explode-film。
  2. 說明寫明技能的用途與使用時機，列出 ISO 爆炸圖、拆解動畫、機構分解等觸發詞。
  3. 指令是 Markdown 格式的工作指南，開頭附上原專案的 GitHub 連結。

原理解析

  • 應用盲點：原專案設計給有程式執行環境的 AI 代理使用，README 列出 Node 18 以上、Python 3.10 以上、ffmpeg 與 Chrome 四項需求。畫面裡每個零件都由程式建模，硬規則寫明不貼圖、不用照片。手機 Gemini 沒有這套環境，原樣照跑不起來。
  • 解決方法：Gemini 讀完專案後，改寫成自己做得到的版本存進技能。說明欄寫的是「3D 模型爆炸圖動畫、ISO 視角投影、組合拆解動畫與相關視覺化工作流程指南」，重點已經從程式建模轉成圖像與動畫生成。
  • 比喻：這像把一份需要專業烤箱與溫控設備的食譜，交給只有電鍋的人改寫。菜名和成品樣貌留著，做法換成電鍋做得到的步驟，成品接近，製程已經不同。
  • 觸發條件：說明欄決定技能什麼時候被自動呼叫出來。之後對話裡出現「爆炸圖」「拆解動畫」等字，Gemini 就可能自動套用；要確定套用，直接輸入 /iso-explode-film 最穩。
PART 02

技能藏在哪一層選單？

定義

手機版 Gemini 把技能與連接器集中在側邊選單的「自訂」底下。Google 這次改版把設定與連結的應用程式收在同一處，網頁版、手機版與桌面版都適用。

操作步驟

  1. 開啟 Gemini App，點左上角的選單圖示（兩條橫線）。
  2. 側邊選單點 自訂，位置在「已排定」與「影片」之間，圖示是一個六角形。
  3. 上方有「探索、連接器、技能」三個分頁，點 技能。
  4. 「已啟用」後面的括號數字是目前啟用中的技能數。要新增技能，點右上角 ＋。

原理解析

  • 應用盲點：側邊選單下方「全部」區是對話紀錄。裡面標題寫著「建立新技能」的項目是過去的一段對話，點進去只會回到那段對話，不會開啟技能管理頁。
  • 解決方法：記住「自訂 → 技能 → ＋」這條路徑，三個點擊位置都在畫面上方，不必往下捲。
PART 03

貼一個網址，技能就寫好了？

定義

點「＋」會跳出兩個選項。運用 Gemini 建立的副標是「說明目標」，由 Gemini 代寫技能；手動建立的副標是「撰寫指令」，由使用者自己填欄位。拿 GitHub 網址建技能，選前者。

操作步驟

  1. 點 運用 Gemini 建立，畫面切到一段對話。
  2. 在輸入框輸入下列文字後送出。 
    請依據 https://github.com/Warrickchenxin/iso-explode-film 建立新技能
  3. Gemini 回覆「已為您建立並更新以下技能」，下方附技能卡片。
  4. 回到「自訂 → 技能」，確認 iso-explode-film 出現在「已啟用」清單，副標寫著「基於 iso-explode-film 專案…」。

原理解析

  • 應用盲點：網址只是 Gemini 讀取的起點。存進技能的是 Gemini 讀完專案後寫的文字指令，原專案裡的腳本、範例工程與字型檔不會一起裝進手機。原專案在電腦上的安裝方式是把整個資料夾複製到 AI 代理的 skills 目錄，兩條路裝進去的份量不同。
  • 解決方法：建好後點進技能內容頁讀一遍指令欄，確認產品類型、視角、標註方式這些重點有寫進去。要調整就直接改欄位文字，頁面右上角會顯示「已儲存」。
  • 另一條路：官方介紹頁提到也可以直接上傳 skill 檔匯入。本例手機截圖的「＋」選單只出現兩個選項，手機版是否提供上傳，以實際畫面為準。
PART 04

呼叫技能，飲水機爆炸圖長什麼樣？

定義

呼叫技能的寫法是斜線/加技能名稱，空一格再接需求。同一段對話可以接著追加要求，例如從靜態爆炸圖延伸成拆解動畫。

操作步驟

  1. 開新對話，輸入下列文字後送出。 
    /iso-explode-film 繪製即熱式飲水機 9:16 爆炸圖
  2. Gemini 產出一張直式爆炸圖。中軸虛線貫穿全圖，零件由上而下分層展開，左右兩側拉線標註，右側另附 1 到 9 號中英名稱。
  3. 同一段對話接著輸入「拆解動畫」，Gemini 回覆「您的影片已準備好！」並附上影片，封面是組裝完成的飲水機，點播放鍵觀看。
i

截圖中產品名稱前後加了兩組星號想加粗，對話框會照字面送出，不必加。

原理解析

  • 應用盲點：這張爆炸圖是寫實質感的生成影像，零件數與構造沒有依真實產品量測。圖中有四處要核對。左右兩側重複標了同一批零件；右側「8. 水泵」下方多掛一個「流量計」；加熱元件左側寫「即熱加熱模組」，右側寫「即熱加熱器」；畫面中還散落沒有對應說明的「5」「9」兩個編號。
  • 解決方法：拿去簡報或教材前，逐一核對零件名稱與編號，有錯就在同一段對話指出要改的地方重畫，例如「刪除左側標籤，只保留右側 1 到 9 號中英對照」。
  • 用途界線：這類圖適合當說明產品構造的示意圖，不能當拆修依據。原專案每一幀都檢查零件有沒有互相穿插，零件數與層級照真實產品；手機版的成果沒有經過這道檢查。
PART 05

總結

整個流程五步，前兩步找入口，中間兩步建技能，最後一步用技能。每一步都有可以在畫面上確認的記號。

步驟要點的地方畫面位置完成時看到什麼
1選單 → 自訂側邊選單上半部六角形圖示，進入自訂頁
2技能分頁 → ＋自訂頁上方跳出兩個建立選項
3運用 Gemini 建立＋選單第一項切到建立技能的對話
4貼網址＋「建立新技能」對話輸入框回覆附技能卡，清單多一列 iso-explode-film
5/iso-explode-film＋需求新對話輸入框爆炸圖或影片，核對標籤與編號

手機版適合做的事

  • 快速出產品構造示意圖
  • 構想討論、教學或簡報配圖
  • 同一套做法反覆套用到不同產品

需要回到電腦端的情況

  • 要原專案的 30 秒成片與雙配色版本
  • 要零件穿插檢查與真實尺寸
  • 依 README 在 Claude Code 等代理環境安裝整個資料夾
